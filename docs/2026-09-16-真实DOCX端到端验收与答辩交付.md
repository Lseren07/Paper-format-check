
## 3. 误报、漏报控制

已纳入回归测试的误报防护包括：

- 目录条目不得被识别为正文、参考文献或章节标题；
- 表格单元格不得按正文、参考文献条目检测；
- 中文文本优先按东亚字体字段判断，避免因 ASCII 字体字段触发误报；
- 封面标签、封面题目、摘要、外文材料、图表题注和页码按结构定位，避免跨区域套用正文规则；
- 参考文献边界、标题层级与目录一致性均有专门回归测试。

## 5. 答辩演示清单

### 环境

- Python：使用 `backend/.venv`。
- Node：按根目录 `.nvmrc` 使用 Node 20。
- 仅选择有效 `.docx` 文件；不要在演示中选择 `.doc`。

### 启动命令

```powershell
# 终端 1：仓库根目录
backend\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000

# 终端 2
Set-Location frontend
npm.cmd run dev
```

### 演示顺序

1. 打开首页，说明系统只处理 DOCX 格式论文。
2. 上传演示 DOCX，点击“开始检测”。
3. 展示错误总数和单条错误的类型、位置、文本、当前格式、规范要求。
4. 展示“格式分析”区域，说明系统会输出当前文档格式摘要。
5. 点击“下载 PDF 报告”，打开报告并展示规范来源与错误明细。
6. 说明检测任务和临时上传文件的清理机制。
7. 如被问及准确率，说明当前已完成功能与回归验收，准确率统计需要经人工标注真值论文计算，不虚报指标。
